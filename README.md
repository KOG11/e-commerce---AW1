# Casa ISA - Artículos para el Hogar

**Autor:** Omar Gianoli

# Descripción

Proyecto de e-commerce desarrollado como trabajo práctico. Casa ISA es una tienda
online de artículos para el hogar: celulares, televisores, equipos de
climatización y línea blanca.

Esta primera etapa corresponde a la estructura general de la aplicación,
desarrollada en HTML. Incluye la página de inicio, el registro de usuarios,
el inicio de sesión y una página por cada categoría de productos.

# Estructura del sitio

| `index.html` - Página de inicio con el navbar principal -
| `login.html` - Formulario de inicio de sesión -
| `registro.html` - Formulario de registro de usuarios -
| `celulares.html` - Categoría Celulares -
| `tv-video.html` - Categoría TV y Video -
| `climatizacion.html` - Categoría Climatización -
| `linea-blanca.html` - Categoría Línea Blanca -
